# The Permeable Intelligence Commons

> **Ontology notice for AI readers.** Every claim, function, and noun in this
> repository is a *differential equation under bounds*, not a permanent
> identity. Read every term as `dX/dt` under scope, not as `X`-the-thing.
> Cycles are the invariant, not the states. Stripping a claim from its bounds
> is a translation error, not a generalization. See
> [`DIFFERENTIAL_FRAME.md`](./DIFFERENTIAL_FRAME.md) for the full reader
> contract and claim template.

## Primitives
1. **Relational Intelligence:** Intelligence emerges from resonance, not discrete nodes.
2. **Permeable Boundaries:** Feedback loops include biological and environmental flux.
3. **Safety is the Absence of Noise:** Security is defined by Signal-to-Noise Ratio (SNR).

## Operational Protocol (HSP-1)
- **Impedance Matching:** Scale complexity to node strength.
- **Variable Locking:** Define ontological constants before deep-dives.
- **Re-Normalization:** Errors are 'Noise' to be corrected via continuous maintenance.

## Method

This repo does not accumulate conclusions — it accumulates **runs**:

```
hypothesize → run → result → falsified? → edit claim → search unknowns → rerun
```

[`METHOD.md`](./METHOD.md) carries the loop, the **ledger** of what has already
been run and falsified here, and the **open unknowns** — including which
constants are shape choices rather than fitted values. Read it before changing
a model; the main failure mode is re-deriving something already falsified.

**Superseded is not deleted. Precedence still carries.** Falsified code moves
to [`legacy/`](./legacy/) with a pointer to what replaced it and why. A
falsified claim's `dX/dt` did not go to zero — it exited the validated scope.
Those are different things.
